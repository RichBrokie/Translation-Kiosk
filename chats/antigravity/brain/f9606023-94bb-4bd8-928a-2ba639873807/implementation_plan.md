# Install Waydroid & Google Play Services

This plan outlines the steps to install and configure Waydroid natively on your Wayland-enabled Zorin OS laptop, complete with Google Play Services and ARM app support.

## User Review Required

> [!IMPORTANT]
> The installation of Waydroid modifies system states and involves executing `sudo` commands to add repositories and install packages. 
> Later on, you will need to manually visit a Google webpage to register your new Android environment's Device ID so the Google Play Store works correctly.
> I will guide you step-by-step through this process. 

## Open Questions

None at this stage, but be prepared to authorize terminal commands via `sudo` prompts during the execution phase.

## Proposed Changes

We will execute the following steps:

1. **Install Prerequisites**: Install essential tools such as `curl`, `ca-certificates`, `lzip`, and `sqlite3`.
2. **Add Waydroid Repository**: Fetch and add the official Waydroid repository to your APT sources.
3. **Install Waydroid**: Install the `waydroid` system package.
4. **Initialize Waydroid (with GApps)**: Run the initialization to download the Android lineage image bundled with Google Play Services (`GAPPS`).
5. **Install ARM Translation (libhoudini)**: 
   - Since your laptop has an Intel processor, we will clone the `casualsnek/waydroid_script` utility.
   - We will use it to install `libhoudini`, which translates ARM code (what most Android apps are built with) into x86 code so it can run smoothly on your Intel processor.
6. **Device Registration**:
   - Fetch the Android ID generated by Waydroid.
   - Provide you with the URL and the ID to manually register your device with Google to lift the "Uncertified Device" restriction.

## Verification Plan

### Automated Tests
- Check `waydroid status` after installation to ensure the service is running.
- Verify `waydroid app list` to confirm Android package installation.

### Manual Verification
- Launching Waydroid from your application menu.
- Opening the Google Play Store, signing in, and installing a common ARM-only app (e.g., Netflix or a popular game) to confirm ARM translation and GApps are fully functional.
